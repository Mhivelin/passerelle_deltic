Général

Introduction

Bienvenue dans la documentation utilisateur de la plateforme de la passerelle DELTIC. Cette plateforme permet de gérer les passerelles entre les solutions utilisées par l'entreprise DELTIC.

🥅 Objectifs de l'application

L’application a pour but de gérer les liens entre les logiciels des clients de la société DELTIC

⚙️ Installation

  1. Se connecter sur l’invite de commande du serveur (cf :  👀)
  2. Cloner le dépôt :

          git clone https://github.com/Mhivelin/passerelle_deltic

  1. Changer de répertoire courant pour aller dans le dépôt :

          cd passerelle_deltic

  1. Créer un fichier .env ✏️

          touch .env

Ouvrir ce fichier et ajouter les informations suivantes :

          CONN_DB_MILECIA=URL DE LA BASE DE DONNÉES MILECIA
CONN_DB_KARELIS=URL DE LA BASE DE DONNÉES KARELIS
DB_USER=LOGIN
DB_PASS=MDP

  1. Initialiser les variables d’environnements :

          source .env

  1. Importer les librairies et installer le modèle avec :

          python -m pip install -r requirements.txt
alembic upgrade head

✨ Et voilà 🎉

🛠 Utilisation

🚀 Lancer l’application

Pour lancer l’application, exécutez la commande suivante :

          uvicorn main:app --host 0.0.0.0 --port $PORT

Assurez-vous que le port soit ouvert pour permettre la connexion.
